### 🎓 GramNet AI – Multilingual RAG-Based AI Tutor

🔗 [View Repository](https://github.com/kompalwargangotri/gramnet-ai-offline-multilingual-rag-tutor)

Developed an AI-powered multilingual tutoring system using Retrieval-Augmented Generation (RAG) and TinyLLaMA to deliver context-aware educational responses. Implemented semantic search using text chunking, SentenceTransformers embeddings, and FAISS for efficient knowledge retrieval. Integrated a locally hosted TinyLLaMA model through llama.cpp and enabled English, Hindi, and Marathi voice interaction through speech-to-text, translation, and text-to-speech. Added adaptive quizzes and optimized the application for offline-first usage in low-connectivity environments.

**Tech Stack:** Python • RAG • TinyLLaMA • llama.cpp • FAISS • SentenceTransformers • FastAPI • Speech Recognition • Text-to-Speech

🔗 [View Repository](https://github.com/kompalwargangotri/securefin-video-kyc-aml)
